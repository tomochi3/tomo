Webアプリ / PWA

卓球戦績メモ

卓球の試合結果を記録するWebアプリ。セット数だけのクイック記録から、1点ごとのスコアボードまで。ビルド不要の静的サイトで、データは端末のブラウザに保存されます。

  • 11点先取・ジュース・サーブ権の交代を自動判定する1点ごと入力モード
  • 台の横に置いて両者に見せる得点板表示（チェンジエンドで左右も自動入れ替え）
  • QRコードで友だち連携。端末ごとの鍵で暗号化して、試合結果が相手にも自動で届く
  • 相手ごとの勝率・連勝記録、「何勝で1奢り」を数える奢りメモ
  • HTML / CSS / JavaScript
  • PWA
  • localStorage
  • ntfy.sh
  • OpenTimestamps
  • node:test
