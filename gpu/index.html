このページの描き方

  • 背景：WebGPU のシェーダーで、毎フレーム描いています。ポインタの位置には液体ガラスのレンズ、章が画面に入ると光の輪が広がります（未対応）。
  • 見出し：テクスチャを数百枚のタイルに分け、3D の壁として描いています。HTML-in-Canvas が使えるときは HTML のままテクスチャにし（未対応）、使えないときは文字の位置を1文字ずつ測って描き写しています。
  • HTML-in-Canvas は実験中の機能です。Chrome で chrome://flags/#canvas-draw-element を有効にすると見られます。どちらも使えないブラウザでは、ふつうの HTML と CSS で表示します。
