    このページの描き方

    • 背景：WebGPU のシェーダーでマス目を毎フレーム描いています。ステージを移ると視点が横に流れ、クリックやステージの到着で、マスが波のように点灯します（未対応）。
    • 見出し：テクスチャを数百個のブロックに分け、3D に並べて描いています。壊れたブロックは、しばらくすると元に戻ります。HTML-in-Canvas が使えるときは HTML のままテクスチャにし（未対応）、使えないときは文字の位置を1文字ずつ測って描き写しています。
    • HTML-in-Canvas は実験中の機能です。Chrome で chrome://flags/#canvas-draw-element を有効にすると見られます。どちらも使えないブラウザでは、ふつうの HTML と CSS で表示します。
